7.2 Flujo de FK (detalle matemático)

El algoritmo de ForwardKinematics::evaluate(q):

t₀ = Identity
     ↓
Para cada segmento i:
     ↓
tᵢ = tᵢ₋₁                     // transform acumulado del segmento anterior
tᵢ = tᵢ ∘ jointᵢ.origin()     // transform local del joint
tᵢ = tᵢ ∘ jointᵢ.motion(qᵢ)   // movimiento articular
tᵢ = tᵢ ∘ linkᵢ.transform      // eslabón rígido
     ↓
Pose(childᵢ) = (World, childᵢ, tᵢ)

Donde joint.motion(q) para cada tipo:

  • Revolute: Transform3D::from_rotation(UnitQuaternion::from_axis_angle(axis, q))
  • Prismatic: Transform3D::from_translation(direction * q)

7.3 Flujo de Jacobiano (detalle matemático)

7.3.1 Geométrico

Para cada joint i:
  pₑ = posición global del end-effector
  pᵢ = posición del joint i (parent ∘ origin)
  zᵢ = eje del joint i en frame global

  Si Revolute:
    J_linear[:,i] = zᵢ × (pₑ - pᵢ)
    J_angular[:,i] = zᵢ

  Si Prismatic:
    J_linear[:,i] = zᵢ
    J_angular[:,i] = 0

7.3.2 Numérico (diferencias finitas centrales)

Para cada joint i:
  q₊ = q,  q₊[i] += ε
  q₋ = q,  q₋[i] -= ε

  p₊ = FK(q₊).end_effector_position
  p₋ = FK(q₋).end_effector_position

  J_linear[:,i] = (p₊ - p₋) / (2ε)
  J_angular[:,i] = 0  (solo posición)

7.4 Flujo de SceneDiff

SceneDiff::between(old, new, epsilon)

1. Frames eliminados: en old pero no en new
2. Frames agregados: en new pero no en old
3. Frames modificados:
   - Distancia euclídea de traslación: ‖t_new − t_old‖
   - Ángulo geodésico de rotación: 2·acos(|q_new · q_old|)
   - Si alguno > epsilon → se reporta como cambio

7.5 Flujo de Primitives

Las primitivas geométricas se construyen en SceneBuilder (o builders específicos como ScaraVisualBuilder) y viajan dentro de VisualScene hasta el frontend.

ScaraVisualBuilder::build(fk, chain)

1. SceneBuilder::from_fk(fk) → VisualScene base (frames + links + axes)
2. Extraer poses de link_1 y link_2 del FKResult
3. Crear primitives:
   - "base_column": Cylinder(radius=0.08, height=0.4) en [0, 0, -0.2]
   - "link_1_body": cylinder_between(world, link_1, radius=0.045)
   - "link_2_body": cylinder_between(link_1, link_2, radius=0.035)
4. Pushear primitives a scene.primitives
5. Devolver VisualScene completa

En el frontend, ThreeRendererService.renderPrimitives() recorre las primitives y crea meshes Three.js:

Por cada primitiva:
  geometry → switch(type):
    Cylinder → CylinderGeometry(radius, height)
    Sphere   → SphereGeometry(radius)
    Box      → BoxGeometry(width, height, depth)

  color ← heuristic: id.includes("column") → gris
                         id.includes("link_1") → azul
                         id.includes("link_2") → verde

  mesh = new Mesh(geometry, material)
  mesh.position = primitive.translation
  mesh.quaternion = [rot.y, rot.z, rot.w, rot.x]  // Rust → Three.js
