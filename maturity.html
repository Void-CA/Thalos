7  Estado de madurez

Esta sección documenta qué partes de Thalos están estables, cuáles están en desarrollo, y qué esperar de cada área. Es información crítica para colaboradores y adoptantes tempranos.

Estados:

  • \(\blacksquare\) Estable — API congelada, sin cambios breaking esperados
  • \(\blacktriangle\) Desarrollo — Implementado pero puede cambiar
  • \(\circ\) Experimental — Implementación inicial, sujeta a cambios significativos

7.2 Cobertura de tests

7.2.1 thalos-core

  • math::rotations::quaternion — Álgebra de cuaterniones: identidad, inverso, conjugado, norma, normalización, producto de Hamilton, asociatividad
  • math::rotations::unit_quaternion — Invariante de norma, Euler ↔︎ quaternion roundtrip, rotate_vector, composición, inverso, from_axis_angle

7.2.2 thalos-visual

  • validator_tests — Cada invariante del SceneValidator (world, duplicados, topología, conectividad, finitos, quaternions, links, twists)
  • scene_snapshots — Snapshots con insta para validación visual de escenas FK

7.2.3 thalos-api

  • service_tests — SceneService::build_scene con validación
  • api_tests — Integración HTTP: endpoints responden correctamente

7.3 Cobertura deseada

  • Tests directos para Transform3D::compose() y Transform3D::identity()
  • Tests para RevoluteJoint::motion() y PrismaticJoint::motion()
  • Tests para SerialChainBuilder (éxito y error)
  • Integración FK con modelos conocidos
  • Comparación GeometricJacobian vs NumericalJacobian (deberían coincidir dentro de tolerancia)
  • Snapshots por modelo robótico (Planar3R, SCARA, etc.)
  • Tests de frontend con Angular Testing Library
